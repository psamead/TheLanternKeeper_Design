## Lessons worth carrying forward

1. **Small playable scope can carry a larger story.** The scope cut retained a coherent interaction and used storyboards for expansion. For future demos, identify the essential playable route before increasing locations or characters. Evidence: imported York summary and current Demo plan. This is a scoping method, not a reason to shrink every future game.
2. **Completion has several meanings.** The current release records distinguish implementation, browser testing, Windows startup, and owner approval. Preserve those labels in handoffs; a successful build does not establish a successful player route. Evidence: current release report and portfolio status.
3. **Separate design, implementation, and presentation evidence.** Shared design files, Unity reports, and portfolio sources serve different readers. Link them through a short entry point instead of copying old instructions into multiple locations. Evidence: `ForAgent/README.md` and `AGENT_PROCESS_GUIDELINES.md`.
