# The Lantern Keeper portfolio

**The Lantern Keeper — A Tale from the Breton Coast** is a five-page visual introduction to the story, characters, world, Demo flow, and interaction design.

- [Open the portfolio PDF](TheLanternKeeper_Portfolio_2026-11-15_v1.pdf)
- [View all five pages](Previews/TheLanternKeeper_Portfolio_2026-11-15_v1/overview.jpg)
- [Open page previews](Previews/TheLanternKeeper_Portfolio_2026-11-15_v1/)

The PDF has clickable chapter links along the bottom of each page and a link to the supplied full Demo recording. The recording is also included in the editable package under `Source/TheLanternKeeper_Portfolio_2026-11-15_v1/Media/`.

## Pages

1. **Story and identity:** a short story brief, project type, main visual, and the cold-sea / warm-lantern palette.
2. **Characters and objects:** Maela’s concept-to-game development, Soazig’s concept, lantern, ladder, and crate.
3. **Environments and storyboards:** Home and attic environment art, plus selected P/A/B story illustrations and their composition choices.
4. **Game structure:** Start Menu → Prologue P → Home interaction and Story A → Ending B / EndCard, with the ordered trigger route.
5. **Mechanics and code:** gameplay captures, movement controls, interaction gates, attic transition, and short excerpts from the Unity scripts.

## Reading the evidence

Captions distinguish promotional art, source concepts, environment illustrations, menu mockups, storyboards, and Editor gameplay captures. The Home memory comparison uses two similar views from the same 15 November Editor run. The illustrated B5 dock is part of the ending slideshow; the dock is not a playable level in this Demo.

The portfolio omits a student name, course, and individual contribution statement because those details have not been confirmed. The project’s broader story includes chapters and systems beyond the playable Demo; the pages describe only the implemented scope. At export time the PDF did not claim pending Windows or Web releases had been tested.

**Release update (after v1 export):** the Unity workstation later published and browser-tested the Web Demo at [psamead.github.io/TheLanternKeeper2D](https://psamead.github.io/TheLanternKeeper2D/). The Windows x64 package was built and its EXE startup checked, but Windows gameplay remains unverified. These later results are not represented as evidence used to create this PDF. See the [release report](../ForDesignScreenshot/2026-11-15_AtticBaseline_EndCard_Release/after/Release_Report.md).
