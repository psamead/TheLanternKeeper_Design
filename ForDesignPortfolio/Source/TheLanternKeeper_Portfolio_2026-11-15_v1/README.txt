THE LANTERN KEEPER - PORTFOLIO PRODUCTION PACKAGE
Production date: 2026-11-15. Version: v1.

DELIVERABLE
The final 5-page A3 landscape PDF is in ForDesignPortfolio, two levels above
this directory. It contains English copy, clickable chapter navigation and a
relative link to the supplied full Demo recording in this package's Media/.
Keep the PDF and Source/ directory together when moving the portfolio.
Some browser PDF viewers restrict opening local video files. In that case,
open the MP4 directly from Media/ or use a desktop PDF reader.

EDITING
TheLanternKeeper_Portfolio.designcraft is the native editable layout.
TheLanternKeeper_Portfolio.idml is the editable interchange copy for InDesign.
The IDML was reopened and inspected in DesignCraft, not in Adobe InDesign.
No INDD has been generated. Text, graphics, flow diagram and hyperlinks remain
editable. All placed assets are copied into Links/, with original sources and
SHA256 records in asset_manifest.json. Game source files were not modified.

TOOLS
DesignCraft headless page-layout engine through its command API: page design,
text, diagram, hyperlinks, native save, IDML and PDF export.
Bundled Python 3 runtime: Pillow asset inventory/contact sheet; PDFium renders
of final PDF; pypdf inspection of pages, embedded fonts and link annotations.
Neither Photoshop nor InDesign was needed for this production pass.

FONTS AND BRAND
Cinzel Regular and EB Garamond Regular are the game's supplied OFL fonts.
Their source variable TTF files are in Document Fonts/; licences are in
Fonts_or_Licenses/. Courier New is used only for C# source excerpts; it is a
Windows installed font, embedded in the PDF and not redistributed as a TTF.
Palette: sea #1E2633, fog #4A5A6E, gold #E8B45A, paper #F2EBDD.
The existing game title artwork supplies the Hermine/ornamental identity.

EVIDENCE AND LIMITS
Pages 1-3 distinguish promotional art, character development and environment
art. Page 4 labels the menu image as a mockup. Gameplay captures are from
15 November Editor evidence, not a newly tested standalone build.
Page 5 Present/Memory screenshots come from the same FirstBell exploration
run; the views are similar, not pixel-identical. No characters or UI were
manually composited onto environment art to manufacture gameplay evidence.
The video is the supplied 184-second user recording; no frames were extracted
and no replacement recording was requested.
Code_References/ contains eight read-only snapshots from the shared Unity
project used for the four short excerpts. Line wrapping in the portfolio is
editorial; statements are from the actual source. Source presence does not
prove any subsequent release build was tested.
At the time this portfolio was exported, the shared progress record treated
the new Unity fixes and Windows / Web releases as pending. This portfolio makes
no release or player-test claim; later release feedback is recorded in the
shared ForAgent/PORTFOLIO_PRODUCTION_STATUS.md and is not backdated into v1.
Personal student name, course and individual authorship remain unconfirmed;
they have been omitted. The production chain acknowledges AI assistance and
Photoshop cleanup without assigning unsupported personal credit.
